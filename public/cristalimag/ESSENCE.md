# Esencia visual — Cristalimag

No es una web genérica de “construcción”. Es un **taller de vidrio y aluminio** visto como estudio de arquitectura.

## Materiales que deben sentirse en la UI

| Oficio | Traducción visual |
|--------|-------------------|
| Vidrio | Transparencias, blur, brillos fríos, paños de fachada |
| Aluminio | Perfiles oscuros, biseles metálicos, montantes, esquinas de marco |
| Drywall | Rejillas suaves, paneles, líneas de junta |
| Estructura | Travesaños, repetición tipo cercha / pérgola |
| Obra | Contraste tinta / aluminio, rigor de plano |

## Firmas ya en el sitio

- Fondo tipo **muro cortina** (montantes + travesaños)
- Header **vidrio esmerilado**
- Hero con **marco de mampara** y filo de perfil
- Rail de materiales bajo el hero
- Soluciones como **paños** con remate superior distinto por línea
- Proyectos / detalle con **esquinas de ventana**
- Botones con bisel de aluminio

Al añadir páginas o secciones, reutilizar estas metáforas; no importar cards genéricas de SaaS.
